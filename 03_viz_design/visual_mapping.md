# Visual Mapping

## Colour Palette — Generations

Each generation has one fixed colour used consistently across all charts and sections.

| Generation | Birth years | Hex |
|:-----------|:-----------|:----|
| Silent Generation | ≤ 1945 | `#0f4c5c` |
| Babyboomers | 1946–1964 | `#1d7874` |
| Generation X | 1965–1980 | `#679289` |
| Millennials / Gen Y | 1981–1996 | `#f4a259` |
| Generation Z | 1997+ | `#f25c54` |

Dark teal → warm orange/red: cooler = older, warmer = younger. Chosen for contrast and thematic resonance (warmth = urgency for younger generations).
